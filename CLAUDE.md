# Project Guidelines

## Design System

Use the **shadcn design aesthetic** for all HTML/UI work:

- **Dark background**: `#09090b` (zinc-950)
- **Card**: `bg-zinc-900` with `border-zinc-800` and `rounded-2xl`
- **Font**: Inter (load from Google Fonts)
- **Text**: `text-white` for headings, `text-zinc-400` for body/muted
- **Primary button**: `bg-white text-zinc-900 hover:bg-zinc-100`
- **Outline button**: `border-zinc-700 text-zinc-300 hover:bg-zinc-800`
- **Badge/tag**: `bg-zinc-800 border-zinc-700 text-zinc-400 rounded-full uppercase text-xs`
- **Styling**: Use Tailwind CSS via CDN (`https://cdn.tailwindcss.com`) for plain HTML files
